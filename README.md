# 📊 Tech Challenge FIAP - Fase 1  
## Análise de Dados do Marketplace Olist
----

## 🎯 Objetivo

Este projeto tem como objetivo analisar dados do marketplace Olist, com foco na identificação de padrões de comportamento de compra, desempenho logístico, meios de pagamento e performance dos vendedores.

A análise foi desenvolvida com foco estratégico, visando apoiar a tomada de decisão baseada em dados.
